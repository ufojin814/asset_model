# 复现指南（Reproduction Guide）

> 目标：任何 AI 或开发者，仅凭本文档即可从零完整复现本项目（含环境、数据、运行、扩展、推送）。

---

## 0. 环境要求
- **Node.js ≥ 16**（推荐 22.x）。零运行时 `npm` 依赖，无需 `npm install`。
- 操作系统：Windows / macOS / Linux 均可（本项目在 Windows + Git Bash 验证）。
- **真实数据接 Wind 经「直连 Wind CLI」**：数据层直接调用 Wind MCP Skill 的 `node scripts/cli.mjs call ...`（写入参数 JSON → execFile，cwd 切到 skill 目录，`WIND_API_KEY` 经 env 注入），**绕过 Hermes 在复杂取数 prompt 下会循环/挂起（达 240s 超时）的问题**。Hermes Agent 仅保留用于**自然语言语义解析**（`parseIntent`），不可用时回退 `heuristicParse`。`config/hermes.json`（gitignore 保护，不入库）存放 `windMcpSkillPath` 与 `windApiKey`。无 Hermes/Wind 时仍可跑 `local`/`akshare`。
- 网络：运行演示数据（`local`）无需联网；接入 Wind（经 Hermes）/akshare 时需相应权限/Python 环境。

## 1. 获取代码
```bash
git clone git@github.com:ufojin814/asset_model.git
cd asset_model
# 若走 HTTPS 被代理拦截，使用 SSH：git@github.com:ufojin814/asset_model.git
```

## 2. 生成演示数据（必做）
```bash
node scripts/seed_demo_data.js
```
- 在 `data/stocks/` 生成 19 只标的 JSON，在 `data/macro/` 生成 `snapshot.json`。
- **所有数据为 DEMO 种子，清晰标注 `_demo:true`，非实时行情**。真实数据见第 6 节。

## 3. 启动服务
```bash
node server.js
# 默认端口 3300；可改：PORT=8080 node server.js
# 数据提供方（默认 auto）：
#   auto    = Wind(直连CLI) → akshare(Python) → local(演示) 链式降级，保证服务不中断
#   wind    = 仅 Wind
#   akshare = 仅 akshare
#   local   = 仅演示种子（零联网，最快最稳）
# 切换示例：AM_DATAPROVIDER=local node server.js
```
浏览器访问 `http://localhost:3300`。

> ⚠️ 用 `node server.js` 直接前台/后台常驻；**不要**用 `node server.js &` 这类 shell 后台写法——该进程会随 Bash 命令结束被回收，表现为「先成功、随后 ECONNREFUSED」。

## 4. API 速查（均可浏览器/ curl 直接调用）
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/health` | 健康检查（含 `dataProvider` 与 `hermes` 状态） |
| GET | `/api/themes` | 主题列表 |
| GET | `/api/macro` | 运行宏观研判（自动落库） |
| GET | `/api/select?theme=optical_comm&topN=3` | 主题选股（自动落库） |
| GET | `/api/deep?ticker=300308.SZ` | 深度研究（自动落库） |
| POST | `/api/nl-themes` `{"text":"分析光通信和芯片半导体板块","topN":3}` | **自然语言→多主题选股**：Hermes 解析主题，各主题拉真实数据 |
| POST | `/api/nl-deep` `{"text":"对招商银行和兴业银行做深度研究"}` | **自然语言→多标的深度研究**：Hermes 解析全部标的，逐只拉真实数据出 Serenity 报告 |
| GET | `/api/kb` | 资料库索引（可按 `?type=` `?ticker=` 过滤） |
| GET | `/api/kb/<file>` | 读取某份报告原文 |

示例：
```bash
curl http://localhost:3300/api/select?theme=optical_comm | head -c 400
# 自然语言入口
curl -X POST http://localhost:3300/api/nl-themes -H 'Content-Type: application/json' \
  -d '{"text":"分析光通信和芯片半导体板块，哪个更值得配置","topN":3}'
```

## 6. 接入真实数据（已落地：Wind 直连 CLI 主用 + akshare 兜底）
数据与方法解耦，通过 `src/dataProvider.js` 的 `auto` 适配器实现链式降级：`Wind(直连 CLI) → akshare(Python) → local(演示种子)`。默认 `auto`，既跑真实数据又能保证服务不中断（任一层失败自动降级）。

### 6.1 配置（数据直连 Wind CLI；Hermes 仅用于自然语言解析）
编辑 `config/hermes.json`（已 gitignore，**不入库、不回显**），关键字段：
```json
{
  "hermesPath": "C:\\Users\\Administrator\\AppData\\Local\\hermes\\hermes-agent\\venv\\Scripts\\hermes.exe",
  "hermesConfigPath": "C:\\Users\\Administrator\\AppData\\Local\\hermes\\config.yaml",
  "callMode": "cli",
  "timeout": 540000,
  "windMcpSkillPath": "C:\\Users\\Administrator\\.agents\\skills\\wind-mcp-skill",
  "windApiKey": "<Wind API Key>",
  "defaultStocks": ["600519.SH", "000858.SZ", "601318.SH"]
}
```
- `windApiKey` 在调 Wind CLI 时以环境变量 `WIND_API_KEY` 注入子进程（`src/dataProvider.js` 的 `callWindCli`），**绝不写入代码或日志**；`hermesPath`/`hermesConfigPath` 仅 NL 解析（`parseIntent`）用到。
- 无 `config/hermes.json` 时自动回退到 `akshare`/`local`，不影响服务启动。

### 6.2 调用链路（Wind 真实数据）
1. `src/nlIntake.js` → `parseIntent(text)`：调 Hermes 把自然语言拆成 `{themes:[key...], tickers:[名称/代码...], concepts:[自由概念短语...]}`；Hermes 不可用时回退 `heuristicParse`。匹配逻辑走**受控 `CONCEPT_MAP`**（key→触发词列表）：命中主题键→归入 `themes`，否则→`concepts`（交 Wind `search_stocks` 动态兜底）；`parseIntent` 会把 Hermes 与 `heuristicParse` 的 `concepts` 合并，杜绝此前按描述子串盲匹配（如 "AI" 误中光通信）的噪声。
2. `src/hermesClient.js` → `callHermes(prompt)`：把 prompt 写入**纯 ASCII 路径**的 UTF-8 文件，再用 venv 的 python 调 `scripts/hermes_oneshot.py`（`run_oneshot`），彻底绕开 Windows 中文 argv 编码坑；并发信号量 `MAX_CONCURRENT=2` 防止多用户连点耗尽 FD/内存；`extractJSON` 兼容 ```json 围栏/前后缀噪声。
3. **数据拉取（直连 Wind CLI）** `src/dataProvider.js` → `fetchWindStock(ticker)`：并行调 Wind MCP 的 `get_stock_basicinfo` / `get_stock_price_indicators` / `get_stock_technicals` / `get_stock_fundamentals` / `financial_docs.get_financial_news`——写参数 JSON 到 skill 目录后 `execFile(node scripts/cli.mjs call <server> <tool> @scripts/request-*.json)`，cwd 切到 skill 目录，`WIND_API_KEY` 经 env 注入。返回 JSON 经 `parseWindCli`（兼容「单表 / 表数组 / 多行 JSON」三种结构，列名随时间戳用 `fuzzyPick` 模糊匹配，`unit:'%'` 字段自动 ÷100 转小数比）映射为统一 schema，写入 `data/cache/`（TTL 24h，省额度）。
4. 若 Wind 失败/额度不足 → `fetchAkshareStock()`（子进程 Python `akshare`）兜底；再失败 → `localAdapter` 演示数据兜底（标 `_source:'local-demo-fallback'`）。

> ⚠️ **为何数据层绕过 Hermes 取数**：Hermes 在「复杂取数 prompt」下会循环/挂起（达 240s 超时后回退），而 Wind CLI 直接返回结构化 JSON，9–15s 稳定返回真实数据。故**数据层直连 CLI、NL 解析层才用 Hermes**；Hermes 仅作 NL 解析，不可用时回退 `heuristicParse`。

### 6.3 字段 schema（统一，三源一致）
必须包含：`fundamentals.{roa,cfo,roaDelta,cfoMinusRoa,levDelta,curRatioDelta,sharesDelta,gmDelta,atDelta,wc,re,ebit,mvEquity,sales,ta,tl,equity,pe,pb,ps,pePct,pbPct,roe,roic,revGrowth,profitGrowth}` 与 `technicals.{price,ma20,ma60,ma250,rsi14,macdHist,ret12m,ret1m,vol20d,beta}` 与 `news[]`。缺失字段按中性 50 分处理（已做防御）。

### 6.4 接入 akshare（无需 Wind 时）
`pip install akshare` 即可；`akshareAdapter` 以子进程调用 `stock_individual_info_em` / `stock_zh_a_hist` / `stock_a_indicator_lg` 拉取并映射，结果同样缓存。

### 6.5 自然语言股票名 → 代码解析（演示集未收录时兜底）
深度研究 NL 入口 `/api/nl-deep`（`server.js handleNLDeep`）在本地 `aliasMap`（`data/stocks/*.json` 种子）与目标代码/名称都不匹配时，会调用 `src/dataProvider.js` 的 **`resolveWindCode(name)`** 经 Wind 把中文名解析为标准形式代码：
1. 调 `stock_data.get_stock_basicinfo`（NL「查询<名称>股票的基本档案，返回代码、简称、所属行业」）；
2. 兜底调 `stock_data.get_stock_quote`（`windcode` 同时接受名称/代码）；
3. `extractWindCode(obj)` **遍历所有键名**匹配「代码/code」提取首个 `6 位数字(.SH/.SZ)` 形态并规范化为 `XXXXXX.SH/SZ`（6 开头→SH，0/3 开头→SZ）。
- **已知坑**：Wind `get_stock_basicinfo` 返回的代码列名是 **`Wind代码`**（非 `代码`），旧版精确匹配 `pick` 会漏；现改为全键名扫描。
- 解析成功后回填 `code` 与 `resolvedBy:'wind'`，再进入 `deepResearch`。解析失败才报「演示数据集中无此标的，且 Wind 亦未匹配」。
- 例：输入「分析中国卫通」→ 解析为 **601698.SH** → 出完整深度报告（数据源标为 Wind 真实数据）。

## 10. 目录与文件职责（供 AI 快速定位）
- `server.js`：HTTP 路由 + 静态托管 + 报告落库 + **NL 自然语言入口**（`/api/nl-themes`、`/api/nl-deep`）。
- `src/macroAnalyzer.js`：宏观多因子→概率。
- `src/stockSelector.js`：三维评分+统一加权+TopN；⚠️ **金融业（银行/证券/保险等）由 `isFinancial` 识别，跳过 Altman Z / Piotroski F（模型不适用于金融机构，套用会得到 Z≈0 伪「违约」信号），评分中这两项置中性 50 分**。
- `src/sentiment.js`：Loughran-McDonald 情感打分。
- `src/deepResearch.js`：Serenity 九角色框架自动报告；`tierRating` 对金融业走独立评级分支（估值安全边际 + 盈利质量 ROE/PB + 12m 动量），避用 Altman Z / Piotroski F。
- `src/researchDB.js`：时间戳+标的戳落盘与索引。
- `src/dataProvider.js`：auto(降级链)/local/akshare/wind 适配器 + **Wind 直连 CLI**（`callWindCli`/`parseWindCli`/`fuzzyPick`/`resolveWindCode`，兼容单表/表数组/多行 JSON + `unit:'%'`÷100）+ 24h 文件缓存。
- `src/nlIntake.js`：**自然语言语义解析层**（`parseIntent`/`heuristicParse`/`getAliasMap`）。⚠️ 股票别名映射读取 `ticker` 字段（演示种子）或 `code` 字段（Wind 数据），兜底用文件名。
- `src/hermesClient.js`：Hermes Agent 调用层（文件传参 + execFile + 并发信号量 + JSON 提取 + `WIND_API_KEY` 注入）。
- `scripts/hermes_oneshot.py`：Hermes `run_oneshot` 文件传参包装器。
- `config/*`：主题、数据源、框架、宏观因子（**不含 `hermes.json`**）。
- `docs/方法论与学术支撑.md`：全部学术出处。
- `docs/沟通日志.md`：需求沟通与变更记录。
