# 复现指南（Reproduction Guide）

> 目标：任何 AI 或开发者，仅凭本文档即可从零完整复现本项目（含环境、数据、运行、扩展、推送）。

---

## 0. 环境要求
- **Node.js ≥ 16**（推荐 22.x）。零运行时 `npm` 依赖，无需 `npm install`。
- 操作系统：Windows / macOS / Linux 均可（本项目在 Windows + Git Bash 验证）。
- 网络：运行演示数据无需联网；接入 Wind/akshare 时需相应权限/Python 环境。

## 1. 获取代码
```bash
git clone git@github.com:ufojin814/asset_model.git
cd asset_model
# 若走 HTTPS 被代理拦截，使用 SSH：git@github.com:ufojin814/asset_model.git
```

## 2. 生成演示数据（必做）
```bash
node scripts/seed_demo_data.js
```
- 在 `data/stocks/` 生成 19 只标的 JSON，在 `data/macro/` 生成 `snapshot.json`。
- **所有数据为 DEMO 种子，清晰标注 `_demo:true`，非实时行情**。真实数据见第 6 节。

## 3. 启动服务
```bash
node server.js
# 默认端口 3300；可改：PORT=8080 node server.js
# 数据提供方：默认 local；可改：AM_DATAPROVIDER=akshare node server.js
```
浏览器访问 `http://localhost:3300`。

## 4. API 速查（均可浏览器/ curl 直接调用）
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/health` | 健康检查 |
| GET | `/api/themes` | 主题列表 |
| GET | `/api/macro` | 运行宏观研判（自动落库） |
| GET | `/api/select?theme=optical_comm&topN=3` | 主题选股（自动落库） |
| GET | `/api/deep?ticker=300308.SZ` | 深度研究（自动落库） |
| GET | `/api/kb` | 资料库索引（可按 `?type=` `?ticker=` 过滤） |
| GET | `/api/kb/<file>` | 读取某份报告原文 |

示例：
```bash
curl http://localhost:3300/api/select?theme=optical_comm | head -c 400
```

## 5. 冒烟测试
```bash
node tests/smoke.js
```
覆盖：宏观四类资产概率和为 1、选股 Top3 雷达维度完整、深度研究八节结构+落库、资料库有记录。

## 6. 接入真实数据（关键）
数据与方法解耦，通过 `src/dataProvider.js` 切换：
- **Wind（S 级）**：在 `config/wind.json`（已 gitignore）配置 API Key；实现 `windAdapter.getStock/getMacroSnapshot`（参考 `asset_model_analysis` 的 `src/services/windService.js`）。
- **akshare（B/C 级）**：`pip install akshare`；在 `akshareAdapter` 中以子进程调用 Python 拉取 `stock_zh_a_spot_em` / `stock_financial_analysis_indicator` 等，映射为 `data/stocks/{ticker}.json` 的字段schema（见 `scripts/seed_demo_data.js` 的字段定义）。
- 字段 schema 必须包含：`fundamentals.{roa,cfo,roaDelta,cfoMinusRoa,levDelta,curRatioDelta,sharesDelta,gmDelta,atDelta,wc,re,ebit,mvEquity,sales,ta,tl,equity,pe,pb,ps,pePct,pbPct,roe,roic,revGrowth,profitGrowth}` 与 `technicals.{price,ma20,ma60,ma250,rsi14,macdHist,ret12m,ret1m,vol20d,beta}` 与 `news[]`。缺失字段按中性 50 分处理（已做防御）。

## 7. 扩展主题
编辑 `config/themes.json`：新增 `{key,name,description,tickers:[...]}`；确保 `data/stocks/{ticker}.json` 存在即可被 `selectStocks` 纳入。

## 8. 调整研究框架
- 宏观因子权重/σ：`config/macro-indicators.json`（权重含方向符号，citation 见 `docs/方法论与学术支撑.md`）。
- Serenity 框架节点/梯队/熔断：`config/research-framework.json`。
- 选股三维权重：`src/stockSelector.js` 顶部 `W = {fundamental:0.40, technical:0.30, sentiment:0.30}`。
- **任何调整须在 `docs/沟通日志.md` 记录**。

## 9. 提交与推送
```bash
git add -A
git commit -m "feat: 宏观研判/主题选股/深度研究(Serenity) + 研究资料库"
git push origin main   # 或 master，依默认分支
```
- 本项目不提交密钥：`config/wind.json`、`config/hermes.json`、`.env` 已在 `.gitignore`。
- 代理环境若 HTTPS 推送被拦截，使用 SSH（`git@github.com:ufojin814/asset_model.git`）；如遇 `insteadOf` 强制改写，执行 `git config --global --unset url.https://github.com/.insteadof`。

## 10. 目录与文件职责（供 AI 快速定位）
- `server.js`：HTTP 路由 + 静态托管 + 报告落库。
- `src/macroAnalyzer.js`：宏观多因子→概率。
- `src/stockSelector.js`：三维评分+统一加权+TopN。
- `src/sentiment.js`：Loughran-McDonald 情感打分。
- `src/deepResearch.js`：Serenity 九角色框架自动报告。
- `src/researchDB.js`：时间戳+标的戳落盘与索引。
- `src/dataProvider.js`：local/akshare/wind 适配器。
- `config/*`：主题、数据源、框架、宏观因子。
- `docs/方法论与学术支撑.md`：全部学术出处。
- `docs/沟通日志.md`：需求沟通与变更记录。
