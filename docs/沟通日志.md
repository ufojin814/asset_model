### 关键环境发现（重要，影响复现）
- ❗ 本机 git 全局配置 `url.https://github.com/.insteadof=ssh://git@github.com/` **把 SSH 强制改写成了 HTTPS**；而沙箱代理对 github.com 的 HTTPS CONNECT 隧道返回 **502**，导致 `git clone/push` 全部失败。
- 但本机 **SSH 直连 github 成功**（`ssh -T git@github.com` 返回 "Hi ufojin814!"），且绕开代理的直连 HTTPS 也通。
- **解决方案**：`git config --global --unset url.https://github.com/.insteadof`，改用 SSH 协议克隆/推送（已在 `docs/复现指南.md` 第 9 节记录）。
- 参考仓库 `asset_model_analysis` 经 API 返回 404 / 不在公开列表 → 判定为**私有仓库**；但本机 SSH key 为 ufojin814 本人，私有仓库可经 SSH 读。已成功 `git clone` 该仓库研读取框架。
- 参考项目核心：`src/config/team-prompt.txt` 即为 **Serenity 投资研究框架 × Loop Engineering 对抗式迭代**（九角色/节点门禁/双闭环证伪/T1-T5 梯队/八维度个股），这就是用户所说的「白毛股神 serenity 研究框架」。已据此实现深度研究板块。

### 关键决策
- **零依赖**：后端用原生 Node.js HTTP（参考项目同款风格），前端用原生 JS + Canvas 雷达图，无需 `npm install`，开箱即跑。
- **数据策略**：本沙箱无 Wind/Hermes，采用 `dataProvider` 抽象层（local/akshare/wind）。默认 `local` 演示种子数据，**明确标注 DEMO、非实时**，并文档化真实数据接法（见复现指南第 6 节）。严守零虚构原则：缺项标注「数据待补」，不编造。
- **学术支撑贯彻**：宏观概率由多因子信号聚合（Estrella-Mishkin 收益率曲线、Fed model ERP、Shiller 估值、Baur-Lucey 黄金实际利率、Loughran-McDonald 情绪等）；选股三维分别用 Piotroski F-Score、Altman Z、Jegadeesh-Titman 动量、Ang 低波、LM 情感词典。全部出处见于 `docs/方法论与学术支撑.md`。
